GRANDMOTHER DAIRY FARMER — APK BUILD PROJECT

ਇਹ ਪ੍ਰੋਜੈਕਟ GitHub Actions ਨਾਲ Android APK ਬਣਾਉਣ ਲਈ ਹੈ।

ਮੁੱਖ ਫੀਚਰ:
- ਗਾਂ/ਵੱਛੀ ਦੇ ਰਿਕਾਰਡ
- ਦੁੱਧ ਦੀ ਰੋਜ਼ਾਨਾ ਐਂਟਰੀ
- Breeding, heat, service ਅਤੇ calving dates
- Health ਅਤੇ vaccination notes
- Feed notes
- ਫੋਨ ਵਿੱਚ offline save
- JSON backup export/import
- ਪੰਜਾਬੀ/English ਬਟਨ

ਧਿਆਨ:
ਇਹ ਪਹਿਲਾ offline build ਹੈ। 2–3 ਫੋਨਾਂ ਵਿਚ Google sign-in ਅਤੇ cloud sync ਅਜੇ ਇਸ build ਵਿੱਚ ਸ਼ਾਮਲ ਨਹੀਂ ਹਨ।
GitHub ਵਿੱਚ ਇਸ ZIP ਨੂੰ ਸਿਰਫ਼ ZIP ਫਾਈਲ ਵਜੋਂ upload ਨਾ ਕਰੋ। ਪਹਿਲਾਂ Extract ਕਰੋ, ਫਿਰ ਇਸ ਦੇ ਅੰਦਰਲੇ ਸਾਰੇ files/folders repository ਵਿੱਚ upload ਕਰੋ।
GitHub Actions tab ਵਿੱਚ build ਚੱਲੇਗਾ; ਸਫਲ ਹੋਣ ਤੇ Artifacts ਵਿੱਚ APK ਮਿਲੇਗੀ।
