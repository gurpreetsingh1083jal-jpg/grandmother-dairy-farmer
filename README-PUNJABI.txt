GRANDMOTHER DAIRY FARMER - ANDROID APK PROJECT

ਇਹ ਨਵਾਂ ਸਾਫ਼ ਪ੍ਰੋਜੈਕਟ ਹੈ। ZIP ਨੂੰ ਨਵੇਂ ਖਾਲੀ ਫੋਲਡਰ ਵਿੱਚ Extract ਕਰੋ।

GitHub ਤੇ Upload ਕਰਨ ਲਈ:
1. ZIP Extract ਕਰੋ।
2. Extract ਕੀਤੇ Grandmother-Dairy-Farmer ਫੋਲਡਰ ਦੇ ਅੰਦਰਲੀਆਂ ਸਾਰੀਆਂ ਫਾਈਲਾਂ ਅਤੇ .github ਫੋਲਡਰ repository ਦੇ ਮੁੱਖ ਪੰਨੇ ਤੇ Upload ਕਰੋ।
3. Repository ਦੀ branch ਦਾ ਨਾਮ main ਰੱਖੋ।
4. GitHub ਵਿੱਚ Actions ਖੋਲ੍ਹੋ।
5. Build Android APK workflow ਚੁਣੋ ਅਤੇ Run workflow ਦਬਾਓ।
6. Build ਮੁਕੰਮਲ ਹੋਣ ਤੇ workflow run ਦੇ Artifacts ਵਿੱਚ grandmother-dairy-farmer-debug-apk ਡਾਊਨਲੋਡ ਕਰੋ।

ਮਹੱਤਵਪੂਰਨ:
- index.html ਵਿੱਚ ਐਪ ਦਾ ਪੰਜਾਬੀ/English ਰਿਕਾਰਡ ਬੁੱਕ ਕੋਡ ਹੈ।
- Capacitor Android project GitHub Actions ਵਿੱਚ ਆਪਣੇ ਆਪ ਬਣੇਗਾ।
- ਇਹ debug APK ਹੈ; Play Store release/signing ਲਈ ਵੱਖਰੀ signing ਲੋੜੀਂਦੀ ਹੈ।
- ਇਸ ZIP ਵਿੱਚ ਪਹਿਲਾਂ ਦੇ ਵੱਖਰੇ app.js/style.css ਨਹੀਂ ਰੱਖੇ, ਕਿਉਂਕਿ ਮੌਜੂਦਾ ਐਪ ਦਾ code index.html ਵਿੱਚ ਹੀ ਸ਼ਾਮਲ ਹੈ।
