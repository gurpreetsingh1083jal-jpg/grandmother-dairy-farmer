Grandmother Dairy Farmer - Android build package

1. Upload the CONTENTS of this ZIP to the root of your GitHub repository (not the ZIP itself).
2. Commit the files to the main branch.
3. Open the repository's Actions tab.
4. Select "Build Android APK" and run it (or wait for the push-triggered build).
5. When the workflow finishes, open its run, scroll to Artifacts, and download "grandmother-dairy-farmer-apk".
6. Extract the downloaded artifact ZIP; install app-debug.apk on your Android phone.

Note: This package wraps the existing HTML dairy record app as an Android app. The existing app stores records locally on the phone; cloud sync between phones is not implemented in this version.
